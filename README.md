**ARGeometry-ARFrame**
An augmented reality application designed to enhance the learning of geometric concepts through interactive and accessible features. Built for a school assignment, this project incorporates real-time shape detection, volume calculations, and quizzes, along with accessibility features like voice commands and keyboard navigation.

**Features**
Interactive 3D Shape Learning:
Visualize and interact with 3D geometric shapes in augmented reality to understand their properties better.

Shape Detection from Objects:
Detect and identify shapes from real-world objects using AR capabilities.

Real-Time Volume Calculation and Formula Application:
Calculate the volume of detected shapes and apply geometric formulas in real-time.

Interactive Quizzes and Immediate Feedback:
Test your understanding of geometric concepts through quizzes, with instant feedback to reinforce learning.

Accessibility Features:

Voice Command: Hands-free interaction with the application, allowing users to add or manipulate shapes via voice.
Keyboard Navigation: Enables users to navigate and interact with AR elements using keyboard shortcuts.

**Technologies Used**
Frontend: ReactJS, JavaScript (ES6+)
AR Framework: AR.js
Accessibility: Speech Recognition API, Keyboard Navigation
Version Control: Git, GitHub
